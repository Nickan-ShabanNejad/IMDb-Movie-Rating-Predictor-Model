# IMDB Movie Rating Prediction Model

## Overview
This project focused on building predictive models to estimate IMDB movie ratings using statistical learning techniques and exploratory data analysis. The objective was to evaluate which movie-related variables most strongly influence audience ratings and to improve prediction accuracy through model selection and validation.

## Objective
The goal of this project was to develop and evaluate regression-based models capable of predicting IMDB movie scores using structured movie metadata and statistical modeling techniques.

## Methods
- Performed exploratory data analysis (EDA) on movie datasets
- Applied regression modeling techniques using R
- Tested spline regression and interaction effects to capture nonlinear relationships
- Evaluated model performance using cross-validation methods including K-Fold CV and LOOCV
- Compared models using Adjusted R² and Mean Squared Error (MSE)

## Tools Used
- R
- ggplot2
- splines
- boot
- caTools
- Statistical Modeling
- Cross-Validation Techniques

## Key Skills Demonstrated
- Regression analysis
- Predictive modeling
- Statistical analysis
- Data visualization
- Exploratory data analysis
- Feature engineering
- Model evaluation
- Out-of-sample testing

## Results
The project successfully identified several variables that improved prediction performance and demonstrated how spline regression and interaction terms can enhance out-of-sample model accuracy.
